# Data Analyst Jobs 2023 - Monthly Job Postings Trend

## Objective
Analyze monthly trend of Data Analyst job postings in 2023 using Google Sheets.

## Tools Used
- Google Sheets (COUNT, Line Chart)

## Steps
1. Cleaned raw data and created Month-Year column
2. Built summary table with Total Job Postings per month
3. Created Line Chart to visualize monthly trend

## Key Insights
- Job postings varied across months in 2023
- Peak months show higher number of postings for Data Analysts
- Trend helps understand monthly distribution of postings
